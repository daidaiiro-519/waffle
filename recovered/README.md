# 会話の記録から復元した作業ファイル

前のセッションで書いたまま、どこにもコミットされていなかった作業ファイルを、
会話の記録（`~/.claude/projects/<プロジェクト>/<セッションID>.jsonl`）から取り出したもの。

`Write` の内容と、Bash のヒアドキュメントで書いた本文が、記録にそのまま残っている。
同じ名前で複数回書かれているものは、いちばん長いものを採った。

## ここは一時的な置き場である

**中身を精査して、残すものは `src/` などの正しい場所へ移し、このディレクトリは空にする。**
作業領域（`/tmp`）に置いたままだとセッションをまたいで消えるため、いったんここへ避難させた。

## 中身

| ディレクトリ | 本数 | 何が入っているか |
|---|---|---|
| `figures/` | 69 | 図の描画と記法に関わるもの。**このうち下の6本が本体** |
| `scripts/` | 199 | 移行・生成・調査に一度だけ使った道具。出力は既にコミット済みなので、参照用 |

### figures/ の中心となる6本

| ファイル | 役割 |
|---|---|
| `grammar.py` | 図の記法 ── 書ける形を先に決める |
| `figure_schema.py` | 図の宣言の JSON Schema（案） |
| `draw.py` | 宣言から描く。入力の形は主張によらず同じ（items / links / frame） |
| `port.py` | 並びを決める口 ── 点と線から、段と段内の位置だけを返す |
| `svg_graph.py` | 点と線の図を、Graphviz の座標から自前の SVG へ組み立てる |
| `svg_chart.py` | 図表の一族を SVG で直接描く。配置を解かないので Graphviz を通さない |

`build.py` と `build_page17.py` は17種を通す検証の足場で、図の内容を手で書いたリテラルを持つ。
実際の入力の形は `draw.py` の側にある。

## 動かすのに足りないもの

`svg_graph.py` は `pygraphviz` と `dot` を使う。この環境には入っていない。
`svg_chart.py` は座標を解かないので、そのまま動く。

## 次にやること

1. `grammar.py` / `figure_schema.py` / `draw.py` を読み、承認済みの決定
   （16の主張・3つの欄・18の名前）との差分を出す
2. `pygraphviz` と `dot` を入れて動かし、`docs/adr/` に残る50枚の図を再現できるかで、
   復元が完全かを測る
3. 残すものを `src/` へ移し、このディレクトリを消す
