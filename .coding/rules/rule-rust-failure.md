# Rust における失敗の運び方

## 概要

回復可能な失敗を値として運び、回復不能な失敗だけをパニックに任せる。

## 用語と区分

| 区分 | 意味 | 表し方 |
|---|---|---|
| 回復できる失敗 | 入力や外部の状態が、想定の範囲で崩れた | `Result::Err` |
| 回復できない失敗 | 前提そのものが壊れている | `panic!` |

## 規則一覧

| ID | 言明 | 水準 | 適用範囲 |
|---|---|---|---|
| RS-ERR-01 | 回復可能な失敗は `Result` で返し、`panic!` で流さない | 必須 | 公開関数すべて |
| RS-ERR-02 | `()` を失敗型にしない。運ぶ値が無くても、名前のある型を作る | 必須 | 公開関数の失敗型 |

## 規則の詳細

### RS-ERR-01　回復可能な失敗は `Result` で返し、`panic!` で流さない

| 項目 | 内容 |
|---|---|
| 水準 | 必須 |
| 適用範囲 | 公開関数すべて |
| 選んだ理由 | 呼び出し側が回復の可否を選べなくなり、失敗が制御の外へ出る |
| 検証方法 | 公開関数の返り値を読む。取りこぼしの検出は道具に委ねる |
| 違反の見つかり方 | その関数を読むと分かる |

## 適用範囲外

- 失敗をどこへ記録するか

## 委譲する判断

| 何を | どこへ | なぜ |
|---|---|---|
| 取りこぼしの検出 | 道具（宣言が選ぶ） | 機械で見られるため |
