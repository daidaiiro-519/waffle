# Go における失敗の運び方

## 概要

失敗は値として返し、呼び出し元が分岐できる形で運ぶ。

## 用語と区分

| 区分 | 意味 | 表し方 |
|---|---|---|
| 想定内の失敗 | 入力や外部の状態が、想定の範囲で崩れた | 返り値の `error` |
| 想定外の状態 | 前提そのものが壊れている | `panic`。境界で止める |

## 規則一覧

| ID | 言明 | 水準 | 適用範囲 |
|---|---|---|---|
| GO-ERR-01 | 失敗は返り値で返し、`panic` で流さない | 必須 | 公開する関数すべて |
| GO-ERR-02 | 受け取った失敗を包むときは、元の失敗を辿れる形で包む | 必須 | 境界を越えるところ |
| GO-ERR-03 | 失敗を無視しない。無視する場合は理由を残す | 必須 | 全体 |

## 規則の詳細

### GO-ERR-01　失敗は返り値で返し、`panic` で流さない

| 項目 | 内容 |
|---|---|
| 水準 | 必須 |
| 適用範囲 | 公開する関数すべて |
| 選んだ理由 | 呼び出し元が分岐する手段を失い、失敗が制御の外へ出る |
| 検証方法 | 公開関数の返り値の並びを読む。誤りやすい書き方の検出は道具に委ねる |
| 違反の見つかり方 | その関数を読むと分かる。`panic` で流している |

### GO-ERR-02　受け取った失敗を包むときは、元の失敗を辿れる形で包む

| 項目 | 内容 |
|---|---|
| 水準 | 必須 |
| 適用範囲 | 境界を越えるところ |
| 選んだ理由 | 包んだ先で元の失敗を判別できなくなり、呼び出し元が分岐できない |
| 検証方法 | 包んでいる箇所を読み、元の失敗が辿れるかを見る |
| 違反の見つかり方 | 包んでいる1行を読むと分かる |

### GO-ERR-03　失敗を無視しない。無視する場合は理由を残す

| 項目 | 内容 |
|---|---|
| 水準 | 必須 |
| 適用範囲 | 全体 |
| 選んだ理由 | 無視したのか、忘れたのかを、後から読む人が区別できない |
| 検証方法 | 失敗を受け取って使っていない箇所を探す |
| 違反の見つかり方 | その1行を読むと分かる |

## 適用範囲外

- 失敗をどこへ記録するか
- 失敗を呼び出し元へどう見せるか　→　形態の振る舞いが持つ

## 委譲する判断

| 何を | どこへ | なぜ |
|---|---|---|
| 誤りやすい書き方の検出 | 道具（宣言が選ぶ） | 機械で見られるため |
