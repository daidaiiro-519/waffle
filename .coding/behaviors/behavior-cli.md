# 端末から呼ばれるときの振る舞い

## 概要

引数と終了コードで会話が閉じる。内部の作りは保証しない。

## 用語と区分

| 語 | 意味 |
|---|---|
| 結果 | 呼び出し元が使うために出すもの |
| 診断 | 何が起きたかを人へ伝えるもの |

## 保証する振る舞い

| ID | 振る舞い | 検証の単位 |
|---|---|---|
| CLI-01 | 終了コードは `0` と `0` 以外の2値に留め、細かく区分しない | 端から端まで |
| CLI-02 | 結果は標準出力へ、診断は標準エラーへ出す | 端から端まで |
| CLI-03 | 標準出力へ、結果以外を書かない | 端から端まで |

## 保証しない振る舞い

| 何を | 保証しない理由 |
|---|---|
| 内部のパッケージ構成 | 呼び出し元から観測できない |
| 診断の文面 | 変わりうる。空でないことだけを確かめる |
| 応答の速さ | 保証していない |

## 振る舞いの詳細

### CLI-01　終了コードは `0` と `0` 以外の2値に留める

| 項目 | 内容 |
|---|---|
| 入力 | 何らかの呼び出し |
| 期待する結果 | 成功なら `0`、それ以外は `0` 以外 |
| 検証の単位 | 端から端まで |
| 違反の現れ方 | 呼び出し元が、数値ごとの意味を覚えることになる |

**細かく区分しないのは、私たちの選択である。**終了コードに複数の値を使えることは、呼び出し元の仕組みが許している。

### CLI-02　結果は標準出力へ、診断は標準エラーへ出す

| 項目 | 内容 |
|---|---|
| 入力 | 何らかの呼び出し |
| 期待する結果 | 標準出力に結果だけ、標準エラーに診断 |
| 検証の単位 | 端から端まで |
| 違反の現れ方 | 標準出力をそのまま次へ渡せなくなる |

## 適用範囲外

- どの終了コードを、どの場合に返すか　→　仕様が持つ
- ほかの道具から呼ばれたときの振る舞い　→　`form = mcp-server` が持つ

## 委譲する判断

| 何を | どこへ | なぜ |
|---|---|---|
| 引数の解釈の仕方 | 言語の規則と道具 | 言語ごとに定石が違うため |
