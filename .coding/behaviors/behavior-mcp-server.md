# ほかの道具から呼ばれるときの振る舞い

## 概要

会話が続く前提で、呼び出し元が次の一手を決められる形で返す。

## 用語と区分

| 語 | 意味 |
|---|---|
| 会話 | 接続が保たれている間の、複数回のやり取り |
| 手続き | 呼び出し元が名前で呼べるもの |

## 保証する振る舞い

| ID | 振る舞い | 検証の単位 |
|---|---|---|
| MCP-01 | 呼べる手続きの一覧を、問われたら返す | 端から端まで |
| MCP-02 | 知らない手続きを求められたら、失敗として返し、会話を切らない | 端から端まで |
| MCP-03 | 会話をまたいで、前の呼び出しの状態を持ち越さない | 結合 |

## 保証しない振る舞い

| 何を | 保証しない理由 |
|---|---|
| 内部のパッケージ構成 | 呼び出し元から観測できない |
| 応答の速さ | 保証していない |
| 常駐しているかどうか | **外から観測できない。**振る舞いではない |

## 振る舞いの詳細

### MCP-02　知らない手続きを求められたら、失敗として返し、会話を切らない

| 項目 | 内容 |
|---|---|
| 入力 | 一覧に無い手続きの求め |
| 期待する結果 | 失敗の応答が返り、会話は続く |
| 検証の単位 | 端から端まで |
| 違反の現れ方 | 会話が切れ、呼び出し元が最初からやり直すことになる |

### MCP-03　会話をまたいで、前の呼び出しの状態を持ち越さない

| 項目 | 内容 |
|---|---|
| 入力 | 同じ求めを2回続けて |
| 期待する結果 | 2回とも同じ結果 |
| 検証の単位 | 結合 |
| 違反の現れ方 | 2回目の結果が変わる。前の呼び出しが残っている |

## 適用範囲外

- どんな手続きを持つか、その引数の形　→　仕様と、呼び出し元の仕様が持つ
- 端末から呼ばれたときの振る舞い　→　`form = cli` が持つ

## 委譲する判断

| 何を | どこへ | なぜ |
|---|---|---|
| 手続きの名前と引数の形 | 呼び出し元の仕様 | こちらが決められない |
