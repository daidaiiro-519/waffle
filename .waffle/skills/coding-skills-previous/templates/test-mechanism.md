# 《言語》におけるテストの仕組み

## 概要

**《テストをどう走らせ、どう書くかを一文で》**

## 保証する振る舞い

| ID | 振る舞い | 検証の単位 |
|---|---|---|
| 《ID》 | 《外から観測できる形で一文》 | 《単体／結合／端から端まで／─》 |

**一覧は導出物である。**`python3 scripts/relist.py` が詳細から書き出す。手で書き換えない。

## 保証しない振る舞い

| 何を | 保証しない理由 | 代わりに何で担保するか |
|---|---|---|
| 《保証の外にあること》 | 《この層では決まらない理由》 | 《どこで担保するか》 |

## 振る舞いの詳細

### 《ID》　《振る舞いを述べる一文》

| 項目 | 内容 |
|---|---|
| 前提 | 《成り立つ前提》 |
| 入力 | 《与えるもの》 |
| 期待する結果 | 《観測できる形》 |
| 検証の単位 | 《単体／結合／端から端まで》 |
| 失敗したときの現れ方 | 《どう現れるか》 |
| 失敗の切り分け | 《落ちたとき、どこを疑うか》 |

**芯（ID・言明・検証方法・出典）は `rule-core.md` が定める。**
上の表に在るのは、この種別が足す欄だけである ── **写して使うときは、芯の欄も足す。**

## 走らせ方

| 項目 | 定め |
|---|---|
| 実行コマンド | `《コマンド》` |
| 検出のされ方 | 《どこに書けばテストとして走るか》 |
| 並列 | 《既定で並列か。順序に依存しない書き方》 |
| 失敗の表示 | 《期待と実際が両方出る形》 |

## テストの書き方

| 項目 | 規則 |
|---|---|
| 名前 | 《振る舞いを述べる文にする。実装の名前を含めない》 |
| 構成 | 《前提・実行・確認の3段》 |
| 表明 | 《失敗時に差分が出る形》 |

**適合例**

```《言語》
《振る舞いを名前で述べているテスト》
```

**違反例**

```《言語》
《番号や実装名で名づけたテスト》
```
