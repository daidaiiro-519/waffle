# Hook が保証する振る舞い

## 概要

**呼び出し元から見た入出力と終了コードを保証し、内部の作りは保証しない。**

## 保証する振る舞い

| ID | 振る舞い | 検証の単位 |
|---|---|---|
| HK-AC-01 | 正しい要求に対し、1行の JSON と終了コード `0` を返す | 端から端まで |
| HK-AC-02 | 壊れた要求に対し、終了コード `1` と、原因を示す診断を返す | 端から端まで |
| HK-AC-03 | 標準出力へ応答以外を書かない | 端から端まで |
| HK-AC-04 | 1 MiB を超える要求を、内部の失敗ではなく要求の不備として扱う | 端から端まで |

## 保証しない振る舞い

| 何を | 保証しない理由 | 代わりに何で担保するか |
|---|---|---|
| 内部のモジュール構成 | 呼び出し元から観測できない | 層の規約と依存の検査 |
| 応答の生成に要した時間 | 呼び出し元の仕様が定めていない | 起動の規約（100 ms 以内に書き始める） |
| 診断の文面 | 変わりうる | 診断が空でないことだけを確かめる |
| 同じ要求に同じ応答が返ること | 呼び出し元の仕様が定めていない（Hook 文書に冪等性の記述は無い）。状態を持たなくても、時刻・乱数・外部を読めば応答は変わる | 起動と終了の規約（状態を次の呼び出しへ持ち越さない） |

## 振る舞いの詳細

### HK-AC-01　正しい要求に対し、1行の JSON と終了コード `0` を返す

| 項目 | 内容 |
|---|---|
| 前提 | 実行ファイルが作られている |
| 入力 | 標準入力へ、契約どおりの1行の JSON |
| 期待する結果 | 標準出力が1行の JSON、終了コードが `0` |
| 検証の単位 | 端から端まで |
| 検証方法 | `cargo test --test hook_stdio` と、そのテストが、応答の行数と終了コードの両方を当てているか |
| 失敗したときの現れ方 | 応答が複数行になる、または終了コードが `0` にならない |
| 失敗の切り分け | 応答が複数行なら、診断が標準出力へ混ざっている |

### HK-AC-02　壊れた要求に対し、終了コード `1` と、原因を示す診断を返す

| 項目 | 内容 |
|---|---|
| 前提 | 実行ファイルが作られている |
| 入力 | 標準入力へ、JSON として読めない1行 |
| 期待する結果 | 標準エラーへ原因を示す診断、終了コードが `1` |
| 検証の単位 | 端から端まで |
| 検証方法 | `cargo test --test hook_stdio broken_request` と、そのテストが、終了コードと診断の両方を確かめているか |
| 失敗したときの現れ方 | 終了コードが `0` になる、または診断が空になる |
| 失敗の切り分け | 終了コードが `0` なら、読み取りの失敗を握り潰している |

### HK-AC-03　標準出力へ応答以外を書かない

| 項目 | 内容 |
|---|---|
| 前提 | 実行ファイルが作られている |
| 入力 | 診断を出す条件を含む要求 |
| 期待する結果 | 標準出力は応答の1行だけ。診断は標準エラーへ出る |
| 検証の単位 | 端から端まで |
| 検証方法 | `cargo test --test hook_stdio stdout_only` と、そのテストが、応答以外の出力を実際に作り出しているか |
| 失敗したときの現れ方 | 呼び出し元の解釈が失敗する |
| 失敗の切り分け | 標準出力が複数行なら、`println!` が診断に使われている |

### HK-AC-04　1 MiB を超える要求を、内部の失敗ではなく要求の不備として扱う

| 項目 | 内容 |
|---|---|
| 前提 | 実行ファイルが作られている |
| 入力 | 1 MiB をわずかに超える1行と、わずかに下回る1行 |
| 期待する結果 | 超えたものは要求の不備として診断を返す。下回るものは通常どおり処理する |
| 検証の単位 | 端から端まで |
| 検証方法 | `cargo test --test hook_stdio oversized` と、そのテストが、1 MiB の境界の両側を当てているか |
| 失敗したときの現れ方 | 終了コードが `2` になる |
| 失敗の切り分け | panic で落ちるなら、上限に達する前に確保しようとしている |

## テストの構成

| 種類 | 対象 | 置き場所 | 実行の速さ |
|---|---|---|---|
| 端から端まで | 実行ファイルの入出力 | `tests/hook_stdio.rs` | 1件あたり100 ms 以内 |
| 結合 | 入力アダプターと業務操作 | 言語 × アーキテクチャの規約が定める | 1件あたり数十ミリ秒 |

## 適用範囲外

| 何を | どの層が決めるか |
|---|---|
| テストが走る仕組み | 言語 |
| テストの置き場所の規則 | 言語 × アーキテクチャ |

## 委譲する判断

| 委譲する判断 | 委譲先 | 委譲する理由 |
|---|---|---|
| 性質テストで入力を広げるか | 実装 | 要求の形の幅で決まる |
