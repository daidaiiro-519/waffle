# scripts ── 機械が回すもの

## 概要

**集める・検証する・索引を出すの3つを、機械が行う。**
同じ問いに同じ範囲が返らないと、そのあとの推論の入力が毎回変わるためである。

## 置くもの

| 命令 | 何をするか | 返すもの |
|---|---|---|
| `collect.py --lang <言語> --purpose <用途>` | 軸の値が一致する規約を集める | 規約と、その中の規則。0件の層も、0件として出す |
| `check.py` | 規約の形を検証する | 食い違いの一覧 |
| `check.py --contracts` | 検査と、それが守っている宣言を並べる | 検査の一覧と、裁けないものの一覧 |
| `index.py` | 索引と数を作り直す | `constraints/INDEX.md`（生成物。手で書き換えない） |
| `tests.py` | scripts の振る舞いを確かめる | テストの結果 |

## 何を対象にするか

| 対象 | 何であるか | 誰が確かめるか |
|---|---|---|
| `constraints/` ・ `references/` ・ `templates/` | **保守し続けるもの** | `check.py` |
| `scripts/` | 振る舞いを持つ | **`tests.py`** ── 文言の照合では裁けない |
| `sources/` | **原典。SSOT** | 誰も確かめない ── 変えないものに契約を課すと、原典が保守対象になる |

## 検査が守っているもの

**検査は、守っている宣言を出典として持つ。**
規則に出典を求めるなら、検査にも同じものを求める ──
`declared_in` が原典、`needle` がその宣言の一文に当たる。

`check.py` は検査を1つも走らせる前に、全ての `needle` が
`declared_in` に実在するかを確かめ、無ければそこで落ちる。

| これで守れること | どう担保されるか |
|---|---|
| **宣言の無い検査を足せない** | `needle` が必須で、しかも実在検査が走る |
| **宣言を消すと気づける** | 消した瞬間、その検査が落ちる |

**一覧は `python3 check.py --contracts` が出す。**
ここに書き写さない ── 写しを持つと、写しがずれる。

## 機械では裁けないもの

**「検査が無い」ことと「検査できない」ことは違う。**
裁けないものは `--contracts` が「人が見る」として並べる ──
同じ層の2本が反対のことを言っていないか、委譲を宣言していない点を
下の層が特殊化していないか、出典の原典がその規則を実際に裏づけているか。

## 読み取りは1か所に畳む

**表はヘッダ行で列名を宣言しているので、位置ではなく列名で読む。**
`_common.py` の `tables()` がその1か所である。

実際に起きたこと（2026-09-06）── 検査ごとに正規表現を書いていて、
3か所が**落ちずに**壊れていた。

| 壊れ方 | 何が起きたか |
|---|---|
| 出典の URL を `<small>` で探していた | 78行すべてを素通りし、「食い違いは無い」と出した |
| 規則の ID をハイフンの数で判定した | 表の1列目の `JSON` を規則と数えた |


`tests.py` は、この3つが再発しないことを確かめる。

## 生成物

**索引と数は生成物である。**
`INDEX.md` を手で書き換えない。参照文書の本文へ数を書かない。
どちらも次の生成で消えるか、`check.py` が落とす。

## 一覧を書き出す

```
python3 scripts/relist.py          詳細から一覧を書き出す
python3 scripts/relist.py --check   正本の一覧が詳細と一致するかを見る
```

**一覧は導出物である。**手で書くと詳細と食い違う ── 実際に、一覧と詳細の両方に在る欄105件のうち36件で値が食い違っていた。
`check.py` の「一覧が、詳細から導出したものと一致する」が、手で書き換えたときに落とす。
