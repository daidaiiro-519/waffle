## 規則の詳細

### 《《LANG》-STY-01》　《規則を一文で》

| 項目 | 内容 |
|---|---|
| 水準 | 《必須／禁止／推奨》 |
| 適用範囲 | 《全体／特定の要素》 |
| 根拠 | 《なぜこの規則が要るか。一文》 |
| 例外 | 《適用されない条件。無ければ「なし」》 |
| 既存コードへの適用 | 《新規のみ／改修時に是正／一括是正》 |

**芯（ID・言明・検証方法・出典）は `rule-core.md` が定める。**
上の表に在るのは、この種別が足す欄だけである ── **写して使うときは、芯の欄も足す。**

**適合例**

```《言語》
《この規則を満たす最小の例》
```

**違反例**

```《言語》
《この規則だけを破っている最小の例》
```

## 整形ツールに委ねる範囲

| 項目 | 委ねる／人が決める |
|---|---|
| 行の折り返し・字下げ・空行 | 《委ねる／人が決める》 |
| 並び順（import・要素） | 《委ねる／人が決める》 |
| 命名 | 人が決める（ツールは綴りの形しか見ない） |

## 命名

| 対象 | 表記 | 例 |
|---|---|---|
| 《型／関数／変数／定数》 | 《表記の規則》 | 《例》 |
