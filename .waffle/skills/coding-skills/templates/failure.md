## 概要

**《何を定める規約かを一文で》**

**一覧は導出物である。**`python3 scripts/relist.py` が詳細から書き出す。手で書き換えない。

## 規則の詳細

### 《《LANG》-ERR-01》　《規則を一文で》

| 項目 | 内容 |
|---|---|
| 水準 | 《必須／禁止／推奨》 |
| 適用範囲 | 《全体／特定の要素》 |
| 根拠 | 《なぜこの規則が要るか。一文》 |
| 例外 | 《適用されない条件。無ければ「なし」》 |
| 既存コードへの適用 | 《新規のみ／改修時に是正／一括是正》 |

**芯（ID・言明・検証方法・出典）は `rule-core.md` が定める。**
上の表に在るのは、この種別が足す欄だけである ── **写して使うときは、芯の欄も足す。**

**適合例**

```《言語》
《この規則を満たす最小の例》
```

**違反例**

```《言語》
《この規則だけを破っている最小の例》
```

## 失敗の区分

| 区分 | 運び方 | 例 |
|---|---|---|
| 回復できる | 《値で返す／例外で流す》 | 《例》 |
| 回復できない | 《止める／巻き戻す》 | 《例》 |

## 失敗の型

| 項目 | 定め |
|---|---|
| 公開する失敗の型 | 《分岐できる形かどうか》 |
| 連鎖 | 《原因を保つ仕組み》 |
