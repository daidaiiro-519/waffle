## 規則の詳細

### 《《LANG》《ARCH》-TP-01》　《規則を一文で》

| 項目 | 内容 |
|---|---|
| 水準 | 《必須／禁止／推奨》 |
| 適用範囲 | 《全体／特定の要素》 |
| 根拠 | 《なぜこの規則が要るか。一文》 |
| 例外 | 《適用されない条件。無ければ「なし」》 |
| 既存コードへの適用 | 《新規のみ／改修時に是正／一括是正》 |

**芯（ID・言明・検証方法・出典）は `rule-core.md` が定める。**
上の表に在るのは、この種別が足す欄だけである ── **写して使うときは、芯の欄も足す。**

**適合例**

```《言語》
《この規則を満たす最小の例》
```

**違反例**

```《言語》
《この規則だけを破っている最小の例》
```
