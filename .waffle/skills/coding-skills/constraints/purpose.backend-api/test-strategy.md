# バックエンドAPI のテストの重心と計画

## 概要

**外部との接触面が広いので、結合を厚くし、端から端までは経路ごとに1本だけ持つ。**

## 保証する振る舞い

| ID | 振る舞い | 検証の単位 |
|---|---|---|
| BA-TS-01 | 重心の配分どおりにテストが在る | ─ |
| BA-TS-02 | すべてのテストが、変更のたびに走る | ─ |

## 振る舞いの詳細

### BA-TS-01　重心の配分どおりにテストが在る

| 項目 | 内容 |
|---|---|
| 前提 | 単位ごとに件数を数えられる |
| 検証の単位 | ─ |
| 検証方法 | 当たる命令が無い。単位ごとのテスト件数を数え、重心の高い単位が最も多いかを見る |
| 失敗したときの現れ方 | 結合が薄いまま公開される |
| 失敗の切り分け | 数が合っていても薄いなら、1件あたりが確かめる幅が広すぎる |

### BA-TS-02　すべてのテストが、変更のたびに走る

| 項目 | 内容 |
|---|---|
| 前提 | 実行が1つの命令で済む |
| 検証の単位 | ─ |
| 検証方法 | 当たる命令が無い。変更を取り込む設定に、すべてのテストを走らせる段が在るかを見る |
| 失敗したときの現れ方 | 走らないテストが残る |
| 失敗の切り分け | 走っているのに落ちないなら、除外の指定が効いている |

## 重心

| 確かめる単位 | 重心 | 根拠 |
|---|---|---|
| 単体 | 高 | 業務の判断が多く、外部を用意せずに確かめられる |
| 結合 | **高** | 入力アダプタの検証・出力アダプタの契約・依存の失敗の扱いが、ここに集まる |
| 端から端まで | 中 | 経路ごとに1本。数を増やすと遅くなり、落ちた原因も分かりにくい |
| 性能 | 低 | 応答の速さは保証していない。運用で計測する |

**Hook と配分が違うのは、外部との接触面が広いためである。**

## 採るテスト観点

| 観点 | 採否 | 理由 |
|---|---|---|
| 境界値 | 採る | 本文の上限（1 MiB）と処理の上限（30 秒）が契約に在る |
| 異常系 | 採る | 400 ・ 404 ・ 409 の扱いが契約に在る |
| 冪等性 | 採る | 同じ要求識別子での再送を保証している |
| 並行性 | 採る | 常駐して複数の要求を同時に受ける |
| 障害注入 | 採る | 依存が失敗したときの応答を保証している |
| 資源の解放 | 採る | 接続の集まりを持つ |
| 後方互換 | 採る | 版を公開している |
| 順序非依存 | 採る | テストが並列に走る |
| 性質テスト | 保留 | 入力の形が定まってから決める |

## テストの計画

| 項目 | 定め |
|---|---|
| 実行のタイミング | コミット前（外部なし）と、変更の取り込み時（外部あり） |
| 通過の条件 | すべて緑。`go test -short` が外部なしで通ること |
| 実行の上限 | 外部なしで2分以内。超えたら、遅い結合を単体へ落とす |
| 対象外 | 負荷試験。運用で計測する |

## カバレッジの扱い

| 項目 | 定め |
|---|---|
| 下限 | **置かない**（数値は振る舞いを保証しない） |
| 使い方 | 未到達の行の一覧を、確かめ漏れの発見に使う |
| 実行 | 変更の取り込み時に測り、増減だけを見る |

## 適用範囲外

| 何を | どの層が決めるか |
|---|---|
| 確かめる単位の境界 | アーキテクチャ |
| テストの置き場所 | 言語 × アーキテクチャ |

## 委譲する判断

| 委譲する判断 | 委譲先 | 委譲する理由 |
|---|---|---|
| 依存を実物で立てるか代役にするか | 実装 | 用意できる環境で決まる |
