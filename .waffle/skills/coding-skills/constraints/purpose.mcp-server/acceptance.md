# MCP サーバーが保証する振る舞い

## 概要

**手順どおりのやり取りと、申告した能力の一致を保証する。**


## 保証する振る舞い

| ID | 振る舞い | 検証の単位 |
|---|---|---|
| MC-AC-01 | 初期化のやり取りに、仕様どおりの応答を返す | 端から端まで |
| MC-AC-02 | 申告した能力は、すべて呼び出せる | 端から端まで |
| MC-AC-03 | 標準出力にはメッセージ以外を出さない | 端から端まで |
| MC-AC-04 | 呼び出しの失敗を、接続を切らずに返す | 結合 |
| MC-AC-05 | 標準入力が閉じたら終了する | 端から端まで |

## 保証しない振る舞い

| 何を | 保証しない理由 | 代わりに何で担保するか |
|---|---|---|
| 能力の中身の正しさ | 用途ではなく、中心の処理の責務である | 中心の処理の単体テスト |
| 応答の速さ | 仕様が定めていない | 起動の規約 |

## 振る舞いの詳細

### MC-AC-01　初期化のやり取りに、仕様どおりの応答を返す

| 項目 | 内容 |
|---|---|
| 前提 | 実行ファイルが作られている |
| 入力 | 仕様どおりの初期化要求 |
| 期待する結果 | 仕様どおりの初期化応答を1行で返し、接続を保つ |
| 検証の単位 | 端から端まで |
| 検証方法 | `cargo test --test mcp_stdio initialize` と、そのテストが、仕様の初期化のやり取りをそのまま流しているか |
| 失敗したときの現れ方 | 呼び出し元が接続を確立できない |
| 失敗の切り分け | 応答が返らないなら、要求を1行として読み切れていない |

### MC-AC-02　申告した能力は、すべて呼び出せる

| 項目 | 内容 |
|---|---|
| 前提 | 能力の一覧を返せる |
| 入力 | 一覧の各能力を、最小の引数で呼ぶ |
| 期待する結果 | どれも「能力が無い」以外の応答を返す |
| 検証の単位 | 端から端まで |
| 検証方法 | `cargo test --test mcp_stdio` と、そのテストが、言明どおりの条件を確かめているか |
| 失敗したときの現れ方 | 申告と実際が食い違う |
| 失敗の切り分け | 申告だけが増えているなら、一覧の作り方が実装から離れている |

### MC-AC-03　標準出力にはメッセージ以外を出さない

| 項目 | 内容 |
|---|---|
| 前提 | 実行ファイルが作られている |
| 入力 | 記録が出る条件を含むやり取り |
| 期待する結果 | 標準出力はメッセージだけ。記録は標準エラーへ出る |
| 検証の単位 | 端から端まで |
| 検証方法 | `cargo test --test mcp_stdio stdout_only` と、そのテストが、メッセージ以外の出力を実際に作り出しているか |
| 失敗したときの現れ方 | 呼び出し元が解釈に失敗する |
| 失敗の切り分け | 相手が解釈に失敗するなら、記録が標準出力へ混ざっている |

### MC-AC-04　呼び出しの失敗を、接続を切らずに返す

| 項目 | 内容 |
|---|---|
| 前提 | 初期化が済んでいて、失敗を起こせる |
| 入力 | 失敗する呼び出しと、その後の正常な呼び出し |
| 期待する結果 | 失敗を応答として返し、その後の呼び出しも処理する |
| 検証の単位 | 結合 |
| 検証方法 | `cargo test --test mcp_stdio tool_error` と、そのテストが、失敗のあとも接続が続くことまで見ているか |
| 失敗したときの現れ方 | プロセスが落ちる |
| 失敗の切り分け | 接続が切れるなら、呼び出しの失敗をプロセスの失敗として扱っている |

### MC-AC-05　標準入力が閉じたら終了する

| 項目 | 内容 |
|---|---|
| 前提 | 初期化が済んでいる |
| 入力 | 標準入力を閉じる |
| 期待する結果 | プロセスが終了する |
| 検証の単位 | 端から端まで |
| 検証方法 | `cargo test --test mcp_stdio shutdown` と、そのテストが、標準入力を実際に閉じているか |
| 失敗したときの現れ方 | プロセスが残る |
| 失敗の切り分け | 終了しないなら、読み取りの終端を待ち続けている |

## テストの構成

| 種類 | 対象 | 置き場所 | 実行の速さ |
|---|---|---|---|
| 単体 | 中心の処理 | 同じファイルの `mod tests` | 数ミリ秒 |
| 結合 | 入力アダプタ | 言語 × アーキテクチャの規約が定める | 数十ミリ秒 |
| 端から端まで | 実行ファイルとのやり取り | `tests/mcp_stdio.rs` | 1件あたり100 ms 以内 |

## 適用範囲外

| 何を | どの層が決めるか |
|---|---|
| 確かめる単位の境界 | アーキテクチャ |
| テストの置き場所 | 言語 × アーキテクチャ |

## 委譲する判断

| 委譲する判断 | 委譲先 | 委譲する理由 |
|---|---|---|
| 能力ごとの引数の最小形 | 実装 | 能力の設計で決まる |
