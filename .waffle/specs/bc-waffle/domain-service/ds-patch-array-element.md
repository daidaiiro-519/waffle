# 鍵で配列の要素を書き換える：ds-patch-array-element

## 概要

- 鍵の宣言と配列、それに要素操作を受け取り、書き換えたあとの配列を返す。
- 足す・欄を直す・取り除くの3つを扱い、どれも鍵を通して要素を指す。
- 配列そのものは受け取るだけで、どの Document から来たかは知らない。

---

## 存在意義

- 2つの集約にまたがる。書き換える相手は Document の中身だが、どの欄が鍵かという物差しは Schema が持っている。どちらの集約も相手の中身を知らないので、この突き合わせをどちらの内側にも置けない。
- この計算はどの集約の状態も変えない。受け取った配列から新しい配列を作って返すだけで、書き戻す先を知らない。

---

## 参照する集約

| 集約 | 触れ方 | 何のために |
|---|---|---|
| agg-document | 参照のみ | 書き換える対象の配列は Document の中身であり、書き換えた結果は Document へ戻される。 |
| agg-schema | 参照のみ | どの欄が鍵かという宣言と、要素に補うべき固定値を得る。 |

---

## 入力と出力

### 受け取るもの

| 名前 | 意味 |
|---|---|
| 要素の鍵 | 配列の中で要素を一意に指す欄の名前。 |
| 配列 | 書き換える対象の、要素の集まり。 |
| 要素操作 | 足す・欄を直す・取り除くのいずれかと、その対象と値。 |
| 要素の固定値 | Schema が要素に宣言する、書き手が決めない値。 |

### 返すもの

| 名前 | 意味 |
|---|---|
| 書き換えたあとの配列 | すべての要素操作を適用した結果。 |
| 適用できなかった操作 | 鍵が見つからない等で受け付けられなかった操作と、その理由。 |

### 決められない入力

- 配列の中に同じ鍵を持つ要素が2つ以上あるとき（要素を一意に指せないため、この計算は答えを持たない。一意性は適合の検証が先に担保する）。
- 鍵の宣言が、要素に実在しない欄を指しているとき。

---

## 受け入れ基準

| 基準 |
|---|
| When 足す操作が与えられたとき、システムは配列の末尾へその要素を加えた配列を返す shall。 |
| When 足す要素に固定値の欄が含まれていないとき、システムはその固定値を補って加える shall。 |
| When 欄を直す操作が与えられたとき、システムは鍵が一致する要素の、指定された欄だけを書き換えた配列を返す shall（鍵と他の欄は変えない）。 |
| When 取り除く操作が与えられたとき、システムは鍵が一致する要素を除いた配列を返す shall。 |
| If 指定された鍵を持つ要素が配列に無いとき、システムはその操作を適用できなかったものとして返し、要素を新たに作らない shall。 |
| If ひとつでも適用できない操作があるとき、システムはどの操作も適用していない配列を返す shall。 |
| While 操作の対象になっていない要素があるとき、システムはそれらの並び順を変えない shall。 |

---

## 受け入れシナリオ

### 足した要素は末尾に付く

| 分類 | 観点 |
|---|---|
| 正常系 | 書き換えの写像：足す位置が定まっているか |

```gherkin
Scenario: 足した要素は末尾に付く
  Given 3件の要素を持つ配列
  When 要素を1件足す
  Then 4件になり、元の3件は同じ順序で先頭から並んでいる
```

### 足す要素に固定値が補われる

| 分類 | 観点 |
|---|---|
| 正常系 | 書き換えの写像：宣言された固定値が欠けたまま残らないか |

```gherkin
Scenario: 足す要素に固定値が補われる
  Given 固定値の欄を宣言している要素の配列
  When 固定値の欄を含めずに要素を足す
  Then 加わった要素に固定値が入っている
```

### 欄を直しても鍵と他の欄は変わらない

| 分類 | 観点 |
|---|---|
| 正常系 | 書き換えの写像：直すことと別物に置き換えることを分けられるか |

```gherkin
Scenario: 欄を直しても鍵と他の欄は変わらない
  Given 鍵と2つの欄を持つ要素
  When 片方の欄だけを直す
  Then その欄だけが変わり、鍵ともう片方の欄は元のまま
```

### 鍵が一致する要素だけが取り除かれる

| 分類 | 観点 |
|---|---|
| 正常系 | 書き換えの写像：指した1件だけに効くか |

```gherkin
Scenario: 鍵が一致する要素だけが取り除かれる
  Given 3件の要素を持つ配列
  When 真ん中の要素の鍵を指して取り除く
  Then 2件になり、残った2件の順序は変わらない
```

### 無い鍵を指しても要素は作られない

| 分類 | 観点 |
|---|---|
| 異常系 | 指し間違い：黙って足すことで埋めないか |

```gherkin
Scenario: 無い鍵を指しても要素は作られない
  Given その鍵を持つ要素が無い配列
  When その鍵を指して欄を直す
  Then 適用できなかった操作として返り、配列の件数は変わらない
```

### 1件でも適用できなければ何も適用しない

| 分類 | 観点 |
|---|---|
| 異常系 | 全か無か：途中まで適用された配列を返さないか |

```gherkin
Scenario: 1件でも適用できなければ何も適用しない
  Given 3件の操作のうち1件が無い鍵を指している
  When 3件をまとめて適用する
  Then 返る配列は操作前と同じ
```
