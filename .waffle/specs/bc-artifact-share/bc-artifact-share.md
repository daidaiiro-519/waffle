# 作った文書を渡した相手に見てもらいコメントを受け取ることを行う境界づけられたコンテキスト：bc-artifact-share

## 概要

- 作った文書を、渡した相手に見てもらい、その場でコメントを受け取るための文脈。文書を作った側は誰に見せるかを決め、見る側は名乗るだけで意見を残せる。
- この文脈では、共有される文書の中身を解釈しない。何が書かれているかではなく、誰が見られるか・いつまで見られるか・どんなコメントが集まったかだけを扱う。

---

## ユビキタス言語

| 用語 | 定義 |
|---|---|
| `文書` | 投稿者が手元で作り、これから公開しようとしているもの。公開されると共有アーティファクトになる。 |
| `共有アーティファクト` | 誰かに見てもらうために公開された、1つの完結した文書。この文脈では中身を解釈せず、公開されている一塊として扱う。 |
| `中身` | 共有アーティファクトとして公開された文書そのもの。公開後は書き換えられず、丸ごと入れ替えることだけができる。 |
| `ArtifactId` | 共有アーティファクト1件を指す識別子。共有URLに現れ、公開してから消えるまで変わらない。 |
| `共有URL` | 閲覧者に渡す、共有アーティファクトを開くための場所。差し替えでも再発行でも変わらない。 |
| `隔離された枠` | 中身が表示される領域。中身はこの枠の外にあるもの（閲覧トークンや他の共有アーティファクト）に手を伸ばせない。 |
| `アーティファクト閲覧トークン` | 共有アーティファクト1件を開くために閲覧者へ渡すもの。公開時に一度だけ発行され、以後は見返せない。再発行すると、それまでのものは使えなくなる。 |
| `プロジェクト` | 複数の共有アーティファクトをまとめて見せるための単位。1つの共有アーティファクトが複数のプロジェクトに属してよい。 |
| `閲覧トークン` | アーティファクト閲覧トークンとプロジェクト閲覧トークンの総称。どちらを指すかが文脈で定まるときに使う。 |
| `プロジェクト閲覧トークン` | プロジェクトに入っている共有アーティファクトをまとめて開くために閲覧者へ渡すもの。個々の共有アーティファクトの公開停止とは無関係に生き続ける。 |
| `所属` | 共有アーティファクトがプロジェクトに入っている状態。人が明示的に選んだときにだけ成立し、中身に書かれた情報では決して変わらない。 |
| `閲覧者` | 閲覧トークンを渡されて共有アーティファクトを見る人。名乗るだけでよく、あらかじめ登録されている必要はない。 |
| `投稿者` | 共有アーティファクトを公開する人。あらかじめ招かれた者に限られ、自分が公開したものだけを扱える。 |
| `合言葉` | 投稿者が自分であることを示すために使う、本人だけが知るもの。招かれた人が初めて入るときに自分で決め、管理者にも見えない。 |
| `管理者` | 投稿者のうち、全員の共有アーティファクトを一覧・公開停止・再発行でき、投稿者を招いたり外したりできる者。他人の中身の差し替えはできない（集まったコメントが何に対するコメントかを、投稿者の知らないうちに変えてしまうため）。 |
| `投稿者の名簿` | 誰が招かれているかを持つ、この文脈の外にある仕組み。招待と外すことは、この名簿への操作として行われる。 |
| `招待` | 管理者が投稿者を増やすこと。自分で名乗り出て投稿者になる経路は無い。 |
| `引き継ぎ` | 共有アーティファクトの投稿者を別の投稿者へ移すこと。管理者だけが行える。投稿者が抜けたあとも、残った者が公開停止や再発行を行えるようにする。 |
| `コメント` | 閲覧者が共有アーティファクトに書き残すもの。名前・本文・判定を持ち、他のコメントへの返信として残すこともできる。 |
| `判定` | コメントに添える3つの選択肢のうちひとつ。ただの意見か、この方向でよいか、直してほしいか。 |
| `差し替え` | 共有アーティファクトの中身だけを新しいものに入れ替えること。共有URLも閲覧トークンも、それまでに集まったコメントも保たれる。 |
| `区切りの記録` | 差し替えが行われた時点にコメントの並びへ残される印。これより前の指摘が、差し替え前の中身に対するものであることを読み取れるようにする。 |
| `公開停止` | 共有アーティファクトを開けない状態にすること。中身もコメントも消えず、あとから再公開できる。 |
| `再公開` | 公開停止した共有アーティファクトを再び開けるようにすること。閲覧トークンは必ず新しくなる。 |
| `識別のための情報` | 共有アーティファクトに添えられる、題名・要約・種別・分類の目印のひとまとまり。文書の中に書かれていれば取り出して控え、書かれていなければ題名だけを投稿者に尋ねる。 |
| `分類の目印` | 共有アーティファクトに付けられる短い語。探しやすくするためだけのもので、誰が見られるかには一切影響しない。 |
| `取り出し` | 共有アーティファクトの中身とコメントを、手元へまとめて持ち出すこと。公開を続けたままでも、公開停止の前でも行える。 |

## ドメインサービス

| 業務サービス | 責務 |
|---|---|
| 閲覧可否の判定 | ある閲覧トークンで、ある共有アーティファクトを開けるかを判定する。共有アーティファクト自身の公開状態と、プロジェクトへの所属の両方を見る必要があるため、どちらか一方だけでは答えを出せない。閲覧トークンと対象を受け取り、開けるかどうかを返す。 |

## 業務サービスシナリオ

### 背景

共有アーティファクトAが公開されており、プロジェクトPに所属している。

### 個別の閲覧トークンで開く

| 分類 | 観点 |
|---|---|
| 正常系 | 共有アーティファクト自身の閲覧トークンで開けることを確かめる |

```gherkin
Given 共有アーティファクトAが公開されている
When Aのアーティファクト閲覧トークンで開こうとする
Then 開ける
```

### プロジェクト閲覧トークンで開く

| 分類 | 観点 |
|---|---|
| 正常系 | 所属先のプロジェクトの閲覧トークンでも開けることを確かめる |

```gherkin
Given 共有アーティファクトAが公開されており、プロジェクトPに所属している
When プロジェクトPのプロジェクト閲覧トークンで開こうとする
Then 開ける
```

### 公開停止したものはプロジェクト閲覧トークンでも開けない

| 分類 | 観点 |
|---|---|
| 境界値 | 個別の公開停止が、プロジェクト経由の閲覧にも及ぶことを確かめる。停止した意図を、プロジェクト閲覧トークンが迂回してはならない |

```gherkin
Given 共有アーティファクトAがプロジェクトPに所属している
And 共有アーティファクトAが公開停止されている
When プロジェクトPのプロジェクト閲覧トークンでAを開こうとする
Then 開けない
```

### 所属していないものは開けない

| 分類 | 観点 |
|---|---|
| 異常系 | プロジェクト閲覧トークンの及ぶ範囲が、所属しているものに限られることを確かめる |

```gherkin
Given 共有アーティファクトBがプロジェクトPに所属していない
When プロジェクトPのプロジェクト閲覧トークンでBを開こうとする
Then 開けない
```

### 再発行前の閲覧トークンは使えない

| 分類 | 観点 |
|---|---|
| 異常系 | 閲覧トークンの再発行が、それまでの閲覧トークンを失効させることを確かめる |

```gherkin
Given 共有アーティファクトAのアーティファクト閲覧トークンが再発行されている
When 再発行前のアーティファクト閲覧トークンで開こうとする
Then 開けない
```
