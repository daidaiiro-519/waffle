# 作った文書を渡した相手に見てもらい反応を受け取ることを行う境界づけられたコンテキスト：bc-artifact-share

## 概要

- 作った文書を、渡した相手に見てもらい、その場で反応を受け取るための文脈。文書を作った側は誰に見せるかを決め、見る側は名乗るだけで意見を残せる。
- この文脈では、共有される文書の中身を解釈しない。何が書かれているかではなく、誰が見られるか・いつまで見られるか・どんな反応が集まったかだけを扱う。

---

## ユビキタス言語

| 用語 | 定義 |
|---|---|
| `共有アーティファクト` | 誰かに見てもらうために公開された、1つの完結した表示物。この文脈では中身を解釈せず、公開されている一塊として扱う。 |
| `中身` | 共有アーティファクトとして公開された表示物そのもの。公開後は一切書き換えられない。 |
| `隔離された枠` | 中身が表示される領域。中身はこの枠の外にあるもの（閲覧の合鍵や他の共有アーティファクト）に手を伸ばせない。 |
| `アーティファクト閲覧トークン` | 共有アーティファクト1件を開くための合鍵。公開時に一度だけ発行され、以後は見返せない。再発行すると、それまでのものは使えなくなる。 |
| `プロジェクト` | 複数の共有アーティファクトをまとめて見せるための単位。1つの共有アーティファクトが複数のプロジェクトに属してよい。 |
| `プロジェクト閲覧トークン` | プロジェクトに入っている共有アーティファクトをまとめて開くための合鍵。個々の共有アーティファクトの公開停止とは無関係に生き続ける。 |
| `所属` | 共有アーティファクトがプロジェクトに入っている状態。人が明示的に選んだときにだけ成立し、中身に書かれた情報では決して変わらない。 |
| `閲覧者` | 合鍵を渡されて共有アーティファクトを見る人。名乗るだけでよく、あらかじめ登録されている必要はない。 |
| `投稿者` | 共有アーティファクトを公開する人。あらかじめ招かれた者に限られる。 |
| `コメント` | 閲覧者が共有アーティファクトに残す反応。名前・本文・判定を持ち、他のコメントへの返信として残すこともできる。 |
| `判定` | コメントに添える意思表示。ただの意見か、この方向でよいか、直してほしいか、の3つ。 |
| `差し替え` | 共有アーティファクトの中身だけを新しいものに入れ替えること。合鍵も、それまでに集まったコメントも保たれる。 |
| `区切りの記録` | 差し替えが行われた時点にコメントの並びへ残される印。これより前の指摘が、差し替え前のものであることを読み取れるようにする。 |
| `公開停止` | 共有アーティファクトを開けない状態にすること。中身もコメントも消えず、あとから再び公開できる。 |
| `再公開` | 公開停止した共有アーティファクトを再び開けるようにすること。合鍵は必ず新しくなる。 |
| `分類の目印` | 共有アーティファクトに付けられる短い語。探しやすくするためだけのもので、誰が見られるかには一切影響しない。 |

## ドメインサービス

| 業務サービス | 責務 |
|---|---|
| 閲覧可否の判定 | ある合鍵で、ある共有アーティファクトを開けるかを判定する。共有アーティファクト自身の公開状態と、プロジェクトへの所属の両方を見る必要があるため、どちらか一方だけでは答えを出せない。合鍵と対象を受け取り、開けるかどうかを返す。 |

## 業務サービスシナリオ

### 背景

共有アーティファクトAが公開されており、プロジェクトPに所属している。

### 個別の合鍵で開く

| 分類 | 観点 |
|---|---|
| 正常系 | 共有アーティファクト自身の合鍵で開けることを確かめる |

```gherkin
Given 共有アーティファクトAが公開されている
When Aのアーティファクト閲覧トークンで開こうとする
Then 開ける
```

### まとめの合鍵で開く

| 分類 | 観点 |
|---|---|
| 正常系 | 所属先のプロジェクトの合鍵でも開けることを確かめる |

```gherkin
Given 共有アーティファクトAが公開されており、プロジェクトPに所属している
When プロジェクトPのプロジェクト閲覧トークンで開こうとする
Then 開ける
```

### 公開停止したものはまとめの合鍵でも開けない

| 分類 | 観点 |
|---|---|
| 境界値 | 個別の公開停止が、プロジェクト経由の閲覧にも及ぶことを確かめる。停止した意図を、まとめの合鍵が迂回してはならない |

```gherkin
Given 共有アーティファクトAがプロジェクトPに所属している
And 共有アーティファクトAが公開停止されている
When プロジェクトPのプロジェクト閲覧トークンでAを開こうとする
Then 開けない
```

### 所属していないものは開けない

| 分類 | 観点 |
|---|---|
| 異常系 | まとめの合鍵の及ぶ範囲が、所属しているものに限られることを確かめる |

```gherkin
Given 共有アーティファクトBがプロジェクトPに所属していない
When プロジェクトPのプロジェクト閲覧トークンでBを開こうとする
Then 開けない
```

### 再発行前の合鍵は使えない

| 分類 | 観点 |
|---|---|
| 異常系 | 合鍵の再発行が、それまでの合鍵を失効させることを確かめる |

```gherkin
Given 共有アーティファクトAのアーティファクト閲覧トークンが再発行されている
When 再発行前のアーティファクト閲覧トークンで開こうとする
Then 開けない
```
