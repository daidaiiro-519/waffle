決定記録の「理由」は**論証の連鎖**として書く。段の種別は左の色で示し、文字を増やさない。

| 段 | 中身 |
|---|---|
| 測った | 出所つきの観測。再測定できる |
| 確かめていない | 判断の土台にしたが検証していない前提。測り直せず、採るか捨てるかしかない |
| だから／一方で／合わせると | 推論の接続。飛躍をここで見せる |
| 結論 | 連鎖の終点。**1つだけ**。途中の段は結論ではなく踏み台 |
| 反証 | **既に観測されている**不利な事実。無ければ「探したが見つからない」と書く |

**崩れる条件**は、**測った段と確かめていない段にだけ1行**で添える。結論には付けない（「上のどれかが崩れたとき」で自明なので、書くと繰り返しになる）。

**Why:** ユーザーが4案から選んだ形（思考の段が視覚的に追える C を主に、主張ごとの弱点を持つ B を枝葉へ）。実地でも効いた——同じ内容を4通りに書いたとき、連鎖で書いた版だけが末尾で「『規約を扱うユースケースだから例外』は測った事実ではなく私の解釈だ」と自認せざるをえなくなった。他の3案では出てこなかった。**「これから崩れうる（崩れる条件）」と「もう崩れかけている（反証）」は別物**で、両方要る。前者だけだと反証不能な断定になり、後者だけだと弁護になる。

**How to apply:** 理由を書くときは、まず測った事実を出所つきで置き、確かめていない前提を隠さず段として立てる。接続語を省かない。反証の欄を空にしない——探した結果として空なら、そう書く。なお確立された論証モデル（トゥールミン）と照らすと、裏付け（論拠がなぜ正当か）にあたるものは **knowledge への参照**として置く。限定（「おそらく」等）は置かない——決定の欄が言い切りを求めているため、範囲の限定は「答えないこと」が持つ。関連: [[adr-granularity-and-decision-abstraction]]
