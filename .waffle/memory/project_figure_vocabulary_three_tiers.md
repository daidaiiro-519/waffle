図の語彙の作り直しは、**既に確立された図解の枠組みから始める**と決めた（2026-08-13）。自分で分類を作らない。

**3段の構造**（ゼラズニー『マッキンゼー流 図解の技術』の手順）: メッセージを決める → 比較の方法を見極める → チャートを選ぶ。いまのWaffleの18部品は**全部3段目（描き方）の名前**で、**2段目が存在しない**。`flowchart` と書く行為は比較の方法を飛ばしていきなりチャートを選んでいる。flowchart 125枚が6つの主張を担っていたのはその必然の結果。

**2段目に置く語彙**（既存の枠組みから採る）:
- 量を主張するもの — FT Visual Vocabulary の9分類（偏差／相関／順位／分布／時間変化／量の大小／全体と部分／空間／流量）。ゼラズニーの5比較はこの部分集合。
- 関係を主張するもの — つながり／階層／包含／順序／循環／対応

**下限の実測**: FTの9分類に対し、いまの17種で表せるのは 全体と部分・量の大小・時間変化・流量・順位（棒で代用）のみ。**分布・偏差・空間が空白、相関が不完全**（散布図が無い）。「Mermaidが下限」の具体的な中身がこれ。関係の側は厚く、量の側が薄い。

**3段目の部品**（一次案10個、未検証）: 箱／結び／囲み／筋／帯／扇／点／軸／面／行。分布には「区間ごとの度数」、偏差には「基準線とそこからの差」が要るので不足がある。

**Why:** ユーザーの要望は「CSSのような形で、決められたルールの範囲内で表現できる」こと。完成品の名前を並べる限り名前の数しか描けない。有限の部品を決めて組み合わせで作る形にすれば、Mermaidのメニューに縛られない組み合わせ（囲みの中に帯、面の片側に入れ子・もう片側に操作と応答）が特別扱いなしに書ける。ddd-advisor から「過去の描画物のクラスタリングから語彙を導くのは、置き換えたい語彙の痕跡から語彙を再生産する手続き」という指摘を受けており、確立された外部の枠組みから採ることでこれを回避する。

**How to apply:** 語彙を決めるとき、まず2段目（何を主張するか）を置き、3段目（描き方）はそこから従属して決まるようにする。部品の過不足は、2段目の全分類を実際に組んでみて測る。関連: [[feedback_relations_in_words_not_symbols]] [[project_figure_notes_table]]
