図を大きくするとき、本文の段幅の外へ出してはいけない。本文の幅の中で大きくする。横に2面並べる比較図なら、**面を縦に積む**と1面が本文幅いっぱいを使えて、横並びの倍以上になる。

**Why:** ユーザーの指摘「本文からはみだすとダメだ。私が大きくしてと言ったのは本文からはみ出さずに大きくしてくださいという依頼でした」。私は「図解がメインにしては小さい」を受けて `width:min(94vw,84rem)` で本文の外へ出し、「大きい画面がはみ出しているのは視認性最悪」と差し戻された。広い画面では左右の余白が消え、本文と図の基準線が揃わなくなる。

**How to apply:** 図が小さいと言われたら、まず「本文の幅の中で使える面積を使い切っているか」を見る。横に並べているなら縦に積むだけで倍になる。副次的な効果として、狭い画面用の特別扱い（media query で縦に積み直す）が不要になり、どの幅でも同じ形になる。あわせて、面ごとの倍率は器が揃えているので、ページ側で `width:100%!important` のような上書きをしないこと（一度これで倍率を壊した）。関連: [[project_svg_visual_check_loop]]
