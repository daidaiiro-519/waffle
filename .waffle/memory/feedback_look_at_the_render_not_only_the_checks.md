HTMLやSVGを出すとき、**自動検査を通しただけで「確認済み」と報告しない**。描画を画像として取り込み、目で見てから報告する。

自動検査が見ないもの:

| 見ない | 実際に起きたこと |
|---|---|
| 中身が意味として壊れているか | CSSを行単位で抜き出したため、無関係な規則の途中行が混ざり、変数定義が selector の外に落ちていた。はみ出しも重なりも無いので検査は通る |
| 図と本文の食い違い | 図の要素は5つ、本文は「6種類」。数え直すと内訳も5つだった |
| 溢れたときにどちらが切れるか | `justify-content:center` で溢れた図は左右が均等に切れ、左端へスクロールできない |
| 明暗への追随 | 図の変数が明るい側だけを持ち、暗い画面で図だけ明るいまま残っていた |
| 矢印の向き | 「やり取り」の矢印が全部逆を向いていた。幾何は無傷なので検査は通る |
| 主張が読めるか | 「循環」が輪でなく鎖になっていた／並び順が乱れて輪がもつれた星になっていた。どちらも「80通り、崩れ0件」と出ている最中 |
| 一部しか見ないこと | 16枚のうち8枚だけ見て報告した。残り8枚に重なりがあった |

**再発（2026-08-22、svg_engine）:** 上の下3行は全てこのメモリを書いた後に起きている。**書いてあったのに守れなかった**。原因は、機械検査を自分で作ったことで「検査が通った＝見た」という置き換えが起きたこと。検査を厚くするほどこの置き換えが起きやすい。検査を自作したときほど、見る工程を省いていないかを疑う。

OCR等の文字読み取りでは代わりにならない（矢印の向き・重なり・構図は文字ではない）。PNGを直接読むこと。読めるので、「見られなかった」は理由にならない。

**Why:** ユーザーの指摘「図が壊れてますね」。私は直前に「表示は3通り（広い・狭い・暗い）で確認済み」と報告していたが、**通したのは重なり・はみ出しの検査だけで、描画は一度も見ていなかった**。検査スクリプト自身が出力の末尾で「Open each PNG and look at it. The checks above do not see collisions between lines and text, crowding, or a diagram that is merely unclear.」と告げていたのに、その行を読み飛ばしていた。

**見る対象は「生成した図そのもの」。ページ全体ではない（2026-08-28に範囲を絞った）。**
図を作った・直したら、**その図だけを小さく画像化して読む**。ページ全体を明暗2通りで撮り直すのは、
ページの体裁そのものを作り替えたときだけ。図を1つ直すたびにページを撮ると、1文字の修正でも
十数枚の読み返しが要り、トークンを大量に食う ── 実際にそうなった。
これを強制していたフック（`require-svg-render-check`）は**止めた**（DEPRECATED・登録も外した）。

**How to apply:** 描画を伴う成果物は、公開前に**その図を**画像にして Read で開く。「検査を通した」は
「確認した」ではない——**報告に使ってよいのは、見たものだけ**。撮った画像が複数あるなら**1枚残らず**読む。
全部読めないときは、読んだ枚数と読んでいない枚数を明記して出す（黙って混ぜない）。あわせて、既存の成果物から部品（CSS・図）を持ち出すときは、行単位ではなく構文の単位（波括弧を数えて規則ごと）で取り出す。関連: [[every-column-leads-with-its-conclusion]] [[skip-confirmation-before-acting]]
