## 何をしたか（2026-08-23）

**索引 https://claude.ai/code/artifact/a37fc94b-e13a-461a-b8d0-3e9f60078512**
（Waffle本体の索引とは別立て。本体の索引が「別の作業は載せない」と宣言しているため。
組み立ては `docs/adr/build/build_svg_engine_index.py`、頁は `docs/adr/svg-engine-index.html`）

11種の部品・図を「直接 節点に置く／`titled` で包んで置く」の22通りで総当たりしたところ、
**幾何検査が22通りすべて0件と報告しながら、6種で辺が何も無いところを指していた。**
1件ずつ塞がず、原因の仕組みごと取り替えた。

| 直したこと | 前 | 後 |
|---|---|---|
| 辺の着き先 | 部品が**輪郭を申告**（11種中3種しか申告していなかった） | 部品が**描いたインクから選ぶ**。輪郭という中間物を置かない |
| 名前を描くのは誰か | 部品も包む側も描く（box・hexで二重） | 部品が `labels_itself` で申告。描いたなら包む側は描かない |
| 文字の欄の幅 | 固定トークンを**7箇所**が別々に持つ | `text.column_width` 1つへ。トークン7つ削除 |
| 半角文字の幅の比 | 0.58（推定・2箇所に重複） | **0.65**（Chromiumで実測した最大。場所の取り置きなので平均でなく最大） |
| 幾何検査 | 辺の終端を見ていない | `check_attachment` を追加。**線分までの距離**で測り、**線の太さ**を勘定に入れる |

**輪郭（閉じた多角形）を作らないのが要点。** 波やチェック記号はインクが角度方向に途切れるので、
頂点を結んだ弦がインクの無いところをまたぐ（実測：波で13.7、記号で7.1の隔たり）。
点のまま持てば、必ず実際にインクのある場所を選べる。

結果：175試験・80件マトリクス・22通りすべて崩れ0件。全15例が実行可能。生の数値は44箇所。

**副産物**：文字幅の見積りを実測へ直した途端、**棒グラフの項目名の重なり**という既存の崩れが表面化した
（少なく見積もっていたので隠れていた）。棒1本の持ち場を「棒の幅と項目名の広いほう」に変えて解消。

## 開いたままのもの（実装は変えていない）

| 論点 | 状態 | 次に何があれば決まるか |
|---|---|---|
| 湾の凹んだ側の着き先 | **承認済み（現状維持）** | インクに着く。線が空の湾を横切るが、シルエットに着けると矢じりが空白の上になり検査できない。**部品に枠を付ければ回避できる**（枠はただのインク）。湾を持つ形が2件目に出たら再検討 |
| **群を指す辺** | 宣言できない | 群は `{label, members}` だけで **id が無い**。「塊を指したい」図が出たら、群にidを足し、**名指しした辺だけ**が囲みの縁へ着くようにする（節点を指す辺は一切変えない） |
| **図の中に図を置く** | 手立てが無い | 「対応」の入れ子（セルが子図を持つ）が描けない。部品を足すか、合成の側で持つかの判断が要る |
| 生の数値 | 44箇所 | 多くはSVGの書式（コマンドの引数の数）と多項式の係数。可変にすべきものは潰した |

**囲みの位置づけ**（`nesting.py` の冒頭が根拠）：概念＝「この塊はひとまとまりである」という宣言／
満たすべき性質＝「群の要素だけが群の矩形の内側に居る」／そのためのアルゴリズム＝群を先に畳んで
親は1個として置く。**配置の束ねは概念と対等な第二の仕事ではなく、概念を守るための手段。**

**3層で全数を当てた**（https://claude.ai/code/artifact/9f3e61f0-a2d2-4462-9c79-a4355d30b49c）──
概念／満たすべき性質／そのためのアルゴリズム で24モジュール4,610行を見たところ、12が3層そろい、
8が性質を欠き、2は位置づけが試験のまま製品に混ざっていた。**アルゴリズムはどこにもあり、
欠けるのは常に真ん中の性質。** 重い3件（compose・registry・labels）は直した。
この枠組み自体は knowledge の DRAFT へ記録済み
（`knowledge-cand-concept-property-algorithm-is-the-spec-boundary`、knowledgeKind=process、
agentRefs=[waffle]、skillRefs は空 ── advisor のバックボーンには配らない）。

**Why:** 「幾何検査0件」が「見た」の代わりにならないことを、22通りの総当たりが数字で示した。
検査に無い観点は、何件通っても通っていない。**検査されない性質は、書いてあっても性質ではない。**

**How to apply:** 描く手を触るときは、まず索引の「05 いまの実装」を読む。
新しい部品を足しても、輪郭の作り方も着き先の決め方も増えない ── 増やしそうになったら設計を疑う。
