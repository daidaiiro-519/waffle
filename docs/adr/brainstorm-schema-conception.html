schema 観の三層

1 　三層は、抽象と具体ではなく、メタレベルである

schema の厚さを比べるのではなく、段が1つ増えると見るのが正しい。 abstract schema は concrete schema を縛り、concrete schema が文書エンティティを縛る。

「値だけを推論させる」という規律は、1段では終わらない。右の列がそれを示している。 concrete schema を書く行為そのものが、構造の推論である。いま domain schema を起こすとき、人とAIが「どんな欄が要るか」を推論している。それを縛るのが abstract schema である。

2 　JSON Schema に足りないもの

JSON Schema は汎用の検証言語であって、スキーマ駆動に特化していない。足りないのは6つだと考える。そのうち5つ目が、図にする価値がある。

4 　論点6　規則を、コマンドで持つか宣言で持つか

abstract schema が操作を固定すると、concrete 固有の規則の行き場が問題になる。 concrete が1つ増えたときに何が起きるかで、2案の差がはっきりする。

私の見解：案B。ただし代償を認める。規則を宣言で書けるということは、宣言で書けない規則は書けないということである。走査・構文解析・グラフの循環検出のような、能力を要する検査は宣言に収まらない。その線をどこに引くかが、この論点の実体である。

5 　論点2　世界の単位は、文書か1つのグラフか

あなたの見解

文書には形式があり、誰が扱うかとの従属関係がある。人間は MD や HTML のようにビジュアライズされたものでないと認知できない ── 読み手の契約である。 AI は MD でも HTML でも JSON でも、そのままコンテキストとして受け取り自然言語として処理する。AI は形式に対するこちらの意図を何も気にしていない。 だから MD でどれだけ構造を整えても、読まれなかったり読み方を伝えなければ、意図どおりには理解しない。 Waffle はその構造を強制的に AI へ認識させ、構造ごとにどう書きどう読むかをスキーマ契約として持たせた。 構造は意味的空間を持つ。「動物」というキーで引けば中身が動物であることは自明で、AI はそこを推論しない。 構造で意味的情報が取れることは、情報の欠損を担保する。 AI は探すとき、機械的な語で grep し、周辺から推論し、それを繰り返して横断する ── その手段はプロンプトではコントロールできない。 Waffle は検索の仕方をスキーマで縛るので、私たちの管理下でコンテキストの読み込みをコントロールできる。

AI 再考見解

単位は、読み手に従属する。私が挙げた3つの根拠は、この1つの原理へ畳める。

足したい条件が2つある

① 構造が意味的空間になるのは、命名が守られているときだけである。 構造は型を保証するが、意味は保証しない。invariants[] に不変条件でないものが書かれても、検証は通る。items のように名前が意味を運ばないキーでは、自明性そのものが消える。 だから 「構造が意味的空間である」は、書き方の指示とセットで初めて成り立つ。 そして帰結が1つある ── 意味は検証できない。だから最後に人の承認が残る。Human On The Loop が消えない理由が、ここで説明できる。

② 構造化の本質的な利得は、「無いことが分かる」ことである。 grep は「見つからなかった」と「無い」を区別できない。探し方が悪かったのか本当に無いのかが決まらない。 構造で引けば「その欄が空である」と言い切れる。不在が観測できるようになる。これがあなたの言う「情報の欠損を担保する」の中身だと読んだ。

取得の冪等 ── ここが空いていた

「手段はプロンプトではコントロールできない」を言い換えると、プロンプトは意図しか運べず、スキーマは手段を運べるということになる。 grep → 周辺から推論 → 横断のループは毎回違う経路を通る。同じ問いに同じ範囲が返る保証がない。つまり検索は冪等ではない。

合意

決定：単位は読み手に従属する。人間が読む検証・状態・承認は文書単位、AI が行う取得・参照は節単位に置く。
理由：二択に見えていたのは「単位」という語が4つの別物を指していたためで、読み手を軸にすると従属で決まる。
次のステップ：論点3（同一性）へ進む。ただし問いが変わった ── 「名前か印か」ではなく、「AI が引く節に、人が読む文書とは別の同一性が要るか」になる。

ここから落ちてきた新しい問い

AI は読み手であると同時に、書き手でもある。書く単位は節（欄を埋める）だが、承認する単位は文書（人が1本として読む）。ここがずれる。 「どこまで書いたら人に見せるか」は、節が何個埋まったかでは決まらず、文書が閉じたときに決まる。このずれが、Human On The Loop の境界そのものである。
