Any Decision Record — 関門1（仕様への橋渡し）

図の宣言を、主張を軸にした形へ置き換える

いまの宣言は、描き方の指定の集まりです。主張は自由記述で別に置かれ、描き方とは対応していません。ここを入れ替えます。

01決定

図の宣言の軸を、描き方の指定から主張へ移す。描き方の指定は宣言から出し、主張から従属して決まるようにする。

主文だけでは読み方が定まらない箇所を、同時に確定させる。

確定させること決定定めないと
主張の持ち方語彙から1つ選ぶ。自由記述の意図は置き換わる同じ主張が別の言い回しで書かれ、揃えられない
描き方の指定宣言から出す。向きも囲みの置き場所も、主張から決まる軸を変えても、描き方の指定が別の鍵として残る
読み方と注釈残す。人が図を読むために要る図の読み方を運ぶ場所が消える

02理由

理由根拠どの決定の理由か主張
主張と描き方が、別々に宣言され互いを縛っていない宣言79件すべてが意図を自由記述で持つ。描画はそれを一切読まず、別の場所の名前だけで描き方を決める主文（軸を主張へ移す）Orchestrator（実測）
自由記述では、同じ主張が別の言い回しになる「〜を示す」「〜を決める」「〜が行き来する」が混在し、揃えられない主張の持ち方（語彙から1つ選ぶ）Orchestrator（実測）
描き方の指定が、宣言と schema の両方に散っている同じ「向き」が両側にあり、schema 側にはさらに20あまりの指定が並ぶ描き方の指定（宣言から出す）Orchestrator（実測）
囲みが、ひとつの主張の専用になっていた他の主張で囲もうとすると規則が拒否する。組み合わせが効かない描き方の指定（主張から決まるようにする）Orchestrator（実測）
図の読み方を運ぶ場所が、他に無い要素を名指しした注釈は、図に載せきれないことを結ぶ唯一の場所読み方と注釈（残す）Orchestrator（実測）

04「宣言の軸」を分けた軸

左の列は満たしたい条件で、満たすものに ○、満たさないものに ✗ を付けた。

満たしたい条件描き方の指定のまま主張を軸にする
主張が、揃った語彙で残る✗ 自由記述のまま○ 残る
描き方を変えても宣言が動かない✗ 動く○ 動かない
囲みや入れ子を、主張を問わず組み合わせられる✗ 主張ごとの特別扱い○ 同じ形で書ける
いまの79件をそのまま使える○ 使える✗ 1件ずつ写す

05答えないこと

論点状態
語彙の名前・欄の名前・条件の書き方仕様で決める。ここで決めるのは軸だけ
79件をいつ誰が写すか引き継ぎの段で決める。写し方（1件ずつ人が判断する）は決まっている

06承認

状態未承認前の2つのADRの決め手を言い直すため、承認を待つ。決定そのものは覆っていない。

07関連

種類対象
