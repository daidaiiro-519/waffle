03決まったことから描いた姿

どちらも決まったことだけから組んである。欄そのものは決めていないので「仮」の印が付く。

何何が見えるか
仕様の文書は、こうなる 業務ユースケース1本 ・ 差し出しの約束 ・ 射影 ・ 承認の材料
関係と、文脈の地図 関係は1件ずつ文書になり、地図は保存せず描く ── 線は文書どうしの参照から導き、 ラベルは関係の宣言から取る。宣言と参照が別入力なので、ずれが違反として出る
