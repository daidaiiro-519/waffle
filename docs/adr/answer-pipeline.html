承認だけで進む ／ 受け渡しの作り

回答が、私に届くまで

画面で押した承認が、どこを通って私に届き、どこで人の一言が要るのか。 部品は4つしかない ── 画面、受け取る役、回答1件のファイル、そして渡す役である。

部品は4つ

部品何をするか置き場所
承認の画面答えを見せ、諾否と書き込みを受け取る。いま在るもの docs/adr/approval-only-simulator.html
serve.py画面を配り、POST された回答をファイルに落とす。 いまの python3 -m http.server を置き換える（30行ほど） docs/adr/serve.py
回答 1件1回の回答が1ファイル。消さずに積む ── 承認したもの・差し戻したもの・書いたことが、あとから順に読める .waffle/answers/<日時>.json
渡す役UserPromptSubmit のフック。 未読の回答があるときだけその中身を私に渡す。無ければ何もしない フック1本

ほかに、形を検査するための JSON Schema を1つ（docs/adr/answer-sheet.schema.json）。 Waffle の schema 体系には入れない ── そこに入れるかは論点17 が未決だから。

止まる場所は、1か所だけ

私が動き出せるのは、あなたが何か書いたときだけです。 ファイルが書かれても、Claude Code が自分でターンを始めることはありません ── だから「Hook で全自動」にはならず、Hook にできるのは、その一言を短くすることです。

あなたが書くもの私が読むもの
フックを置く何でもよい一言（「読んで」でも、次の話でも） 未読の回答ファイル（フックが渡す）
フックを置かない「回答を読んで」と明示する 同じファイル（私が開く）
Artifact から写した JSON を貼る貼られた本文

ファイル1件の中身

{
  "board": "brainstorm-schema-conception-board",
  "answeredAt": "2026-09-09T21:14:00+09:00",
  "answers": [
    { "questionId": "Q1", "topic": "論点14", "title": "型を立てる基準",
      "verdict": "approved",  // approved ｜ returned ｜ unanswered
      "returnReason": null,   // もっと単純に ｜ 前提が違う ｜ 別の道も見たい
      "note": "軸の判定は文書側にも残してほしい" },
    { "questionId": "Q3", "topic": "論点17", "title": "ADR 以外を schema で持つか",
      "verdict": "returned", "returnReason": "前提が違う",
      "note": "hook を散らすと運用が追えない気がする" }
  ]
}
  • 諾否と差し戻しの理由は、値を固定する ── 3値ずつ。schema が検査できるのは、ここまで
  • note は自由文のまま ── 形を決めると、書けることが減る。中身が妥当かは機械には分からない
  • 未回答も1件として残す ── 答えなかったことも情報である
