語彙ごとの描画イメージ

意味の名前で書いたとき、何がどう出るか

文字の部品は宣言・Markdown・プレビューの3列、図は宣言と描いた SVGの2列で並べる。Markdown はその場で描いたもの、プレビューはその Markdown をそのまま見た目にしたもの、図は以前に実際に描かれたものである。

01文字の部品 ── いまの名前と、意味の名前

9つのうち意味として残るのは4つ。2つは同じ意味の重複、2つは器・経路、1つは落とす。

いまの名前意味の名前群
paragraph文意味
list並び（要素の形から導ける）意味
table表意味
code字面意味
kvtable と keyvalue名前と値の組（1つに畳む）重複
section繰り返して入れ子で描く器
object降りる経路
divider—落とす

06描いてみて分かったこと

16すべてを、主張の宣言からその場で描いた。そのうえで機械の検査に掛け、3件の欠陥が出た。いずれも描く手の側にある。

主張何が起きたか何の不足か
偏差負の値が描かれない。基準からの差が正の1本だけ棒になり、負の3本は消え、目盛りの文字だけが枠の外へ出た描く手の不足。いま割り当てている棒の手は、0を下端として扱う。偏差は基準を中間に置く手が要る
やり取り（囲みつき）囲みの下端が、次の行の文字を6px かすめる。囲む範囲を1行増やしても減らしても、境目がどこかの行の文字に当たる描く手の不足。囲み自身が1行を占めるのに、枠の上下の余白がその分を見込んでいない
順序最後の箱が枠の右端に接している余白の不足。読めなくはないが、枠の取り方が中身に追いついていない

変換のために足したもの

主張どの手へ渡したか宣言のどこを写したか
つながり／階層／包含／順序そのまま（主張を軸にした手）—
循環つながりの手最後から最初への結びを足して、環にした
やり取りやり取りの手結びを往復の並びへ。ends: return を戻りとして写した
対応箱組みの手要素を2列に並べた
全体と部分／量の大小／順位／分布割合・棒の手items[].value をそのまま。順位は降順に並べ替えた
時間変化帯の手items[].span を区間へ。軸は目盛りの並びを作って渡した
偏差棒の手frame.baseline を引いた差を値にした（負が描けない）
相関2軸の手items[].at を最大値で正規化した
流量流れの手links[].weight を太さにした
空間箱組みの手1列に並べた

07この一覧から見えること

承認済みの決定で足りないと判定した4つが、実物でも確かめられる。

足りないものこの一覧のどこに出るか
突き合わせる器変更前と変更後が 対応 で書かれている。格子の主張と器を兼ねている
読む必要の度合い文字の部品に一つも無い。この一覧の折り畳みも、宣言からではなく HTML を手で書いている
frame.groupsやり取りの順序に「frame に 'groups' は書けない」という注記が残り、図が描かれていない
差分の語彙変更前と変更後で muted・focus を流用している。落とした・足した・変えた が無い
