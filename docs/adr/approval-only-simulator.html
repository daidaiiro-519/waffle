問い：何を1つの型として立てるか

A　宣言する欄の集合が違えば、別の型にする
同じ欄で書けるなら同じ型とし、違いは種で表す。
代償：「ほぼ同じだが1欄だけ違う」で必ず迷う。閾値を決めることになり、その閾値に根拠が無い
B　軸の集合が違えば別の型。種は、その層で決まることの単位
その領域が何に依存して変わるかを軸として立て、軸の集合が違えば別の型にする。層は軸の組み合わせから導出する。
代償：軸を立てる判断が先に来る。新しい領域では、軸そのものを見つける手間がかかる
C　読み手と用途が違えば、別の型にする
誰が何のために読むかで切る。
代償：同じ構造の文書が、読み手の数だけ増える。読み手は射影で分けられる（論点8）
D　射影先が違えば、別の型にする
SKILL.md になるもの、HTML になるもの…で切る。
代償：形で切ることになり、論点8 と正面から衝突する
落とした案　すべてを1つの型にし、種だけで並べる ── 軸を立てずに種を並べると、種ごとに構造がまるで違うものが1つの型に入る
反証で分かったこと　15と16は欄を見比べていない／「1欄だけ違う」の迷いは軸で問えば消える／ 型は軸の集合、種はその層で決まることの単位
推し　B。ただし前提として論点5・8・15・16 の決着を踏まえていること

記号を選んでください（A・B・C・D、またはどれでもない）
