論点 8

制約は、何を根拠に書けるか

プロジェクトの特性を入れた時点で、抽象概念から外れて具体が混ざりはじめる。排除の規則を別に置くのではなく、出典の必須化で自動的に入らない形にできる。

案中身代償

B出典を推奨にとどめ、無い制約も書ける出典の欄は持つが、空でも成立する空欄が積もる。そして空欄の制約は、誰の経験則なのか分からないまま従われる
C出典の種別だけを区別する（公式／文献／経験則）経験則も書けるが、種別が付くので読み手が重みを判断できるプロジェクト固有の決めごとが「経験則」として入る道が開く。種別が付いていても、集められた時点で従う対象になる
