値オブジェクトvo-schema-ref

型を特定する鍵

Schema Reference

文書が適合する型を、名前と版の組で一意に指す鍵。

鍵であって、写しではない

適合する型そのものではなく、それを特定できる鍵を表す。どの型かが決まればよく、その型が何を宣言しているかは持たない。

持つ属性と、振る舞い

属性

value　文字列

<型の名前>/<版> の形

振る舞い

変わらない。値が等しければ等しい。

指し先の型が新しい版を持っても、この鍵は変わらない

変わるものは、値ではなくエンティティである。

この値だけで常に満たすこと2件

規則担保
値は、実在する型の名前と版を指す検査
名前と版を分けて持たない。分解は、指し先を解決するときに行う型

どの集約のものか

問いが立たない。同一性を持たないので、複数の集約が同じ値オブジェクトを使ってよい。だから置き場所も、集約の下ではなく文脈の直下になる。

これは、型を起こしたあとに描かれる姿を手で描いたものである。描画の機能はまだ無い。欄の定義（必須か・何を書くか）と、いまとの差・そう決めた理由はDomain の型が持つ。
