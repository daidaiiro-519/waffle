論点 14

検査が宣言から導かれていることを、何が担保するのか

論点13 で「検査は宣言から導く」と決めたが、決めただけでは守られない。いまも check.py のコメントには意図が書いてあるが、宣言に辿れない検査が2件残っていた。

1反証を通過した案

案中身代償
