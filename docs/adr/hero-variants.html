3案 ── どれを採るか

主画像を、どう詰めるか

土台は同じ。足すものだけが違う3案を並べる。併用もできるが、1枚に2つ以上の訴求を載せないほうがよいので、まず1つ選ぶ。

Aずれを、図の中に入れる

見出しで「離さない」と言っているのに、離れた状態が絵の中に無い。そこを埋める。

一段の境目に、つながった線2本と、切れた線1本。この道具が消すもの（ずれ）が、はじめて絵の中に出る。ただし層の名前より線に目が行くので、構造の図としては弱くなる。

B1周ごとに、1枚決まる

4つの流れが何を生むのかが、いまは軌道の上の名前だけになっている。

層に番号を振るだけ。線を1本も足さないので構造の見え方を壊さない。ただしずれは相変わらず絵に出ない。

C一段の効果を、対比で見せる

「一段」の意味が、いまは言葉だけ。守らないとどうなるかを並べる。

これは主画像ではなく、説明の図。犬の例えをそのまま絵にしている。主画像の下に置く2枚目としてなら強いが、これ単体では何の道具か分からない。

3案とも同じ部品（docs/adr/build/iso.py）で組んである。併用する場合は、A と C の組み合わせ（主画像＋説明）が自然になる。
