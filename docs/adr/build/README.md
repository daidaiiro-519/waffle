# ADR の組み立て

`docs/adr/*.html` は、ここのスクリプトが生成する。**HTML を直接編集しない** ──
直すときはスクリプトを直して動かす。直接編集すると、次に生成したときに消える。

## 動かし方

```
python3 docs/adr/build/build_<名前>.py
```

出力先はスクリプト内に絶対パスで書いてある。

| ファイル | 何か |
|---|---|
| `_common.py` | 見た目と、節・表・折りたたみ・理由の連鎖を組む道具 |
| `newfmt.css` | 土台の見た目。`_common.py` が読む |
| `build_*.py` | ADR・完成イメージ1枚につき1本 |
| `assert_render.py` | 主張（16種）から図を描く。宣言を受け取り SVG を返す |
| `figs16.py` / `inline_fig.py` / `inline_css.py` / `md2html.py` | 図と見た目を頁へ流し込む小道具 |

## 出す前に通す

```
python3 docs/adr/build/check_all.py
```

3つをまとめて見る ── 表の列数（縦の結合も数える）／図の文字が箱からはみ出していないか／
他の決定への言及に付けた状態と、落とすと決めた語の残り。既定は生きている頁だけ。

**これで見ていないものが1つある** ── 図の線と文字の衝突。
`render_svg_check.py` で描いて、**PNG を1枚ずつ目で見る**。

## 組み立ての無い頁

`docs/adr/figure-notation.html`（図解の記法）は、**公開版から取り戻したもの**で、
ここに組み立てが無い。描いているのは `recovered/figures/` の一式で、
`svg_graph.py` が `pygraphviz` と `dot` を要るが、この環境に入っていない。

**この頁は HTML を直接編集してよい**（再生成で消える心配が無いため）。
入れ直したくなったら、`recovered/figures/` を動かせるようにするのが先。

## 動かないものがある

次の5本は、測定の出力（`*.json`）を入力に取るが、**その出力が残っていない**。

`build_doc_adr` / `build_gallery2` / `build_idx_preview` / `build_index_adr` / `build_parts_adr`

測定をやり直せば作れる。コードは揃っているので、足りないのは入力だけである。

## なぜここに置くか

以前は作業領域（`/tmp`）に置いていて、**2度消えた**。
成果物（HTML）だけが git に残り、それを作る手段のほうが揮発していた。
`recovered/` は会話の記録から取り出した避難所で、ここはその避難を要らなくするための置き場である。
