# MCP サーバーが保証する振る舞い

## 概要

**手順どおりのやり取りと、申告した能力の一致を保証する。**

> **この規約は、原文の照合がまだ済んでいない。**

## 保証する振る舞い

| ID | 振る舞い | 検証の単位 | 前提条件 | 失敗したときの現れ方 |
|---|---|---|---|---|
| MC-AC-01 | 初期化のやり取りに、仕様どおりの応答を返す | 端から端まで | 実行ファイルが在る | 呼び出し元が接続を確立できない |
| MC-AC-02 | 申告した能力は、すべて呼び出せる | 端から端まで | 能力が1つ以上ある | 申告と実際が食い違う |
| MC-AC-03 | 標準出力にはメッセージ以外を出さない | 端から端まで | ─ | 呼び出し元が解釈に失敗する |
| MC-AC-04 | 呼び出しの失敗を、接続を切らずに返す | 結合 | 失敗を起こせる | プロセスが落ちる |
| MC-AC-05 | 標準入力が閉じたら終了する | 端から端まで | ─ | プロセスが残る |

## 保証しない振る舞い

| 何を | 保証しない理由 | 代わりに何で担保するか |
|---|---|---|
| 能力の中身の正しさ | 用途ではなく、中心の処理の責務である | 中心の処理の単体テスト |
| 応答の速さ | 仕様が定めていない | 起動の規約 |

## 振る舞いの詳細

### MC-AC-02　申告した能力は、すべて呼び出せる

| 項目 | 内容 |
|---|---|
| 前提 | 能力の一覧を返せる |
| 入力 | 一覧の各能力を、最小の引数で呼ぶ |
| 期待する結果 | どれも「能力が無い」以外の応答を返す |
| 検証の単位 | 端から端まで |
| 実行コマンド | `cargo test --test mcp_stdio` |
| 失敗の切り分け | 申告だけが増えているなら、一覧の作り方が実装から離れている |

## テストの構成

| 種類 | 対象 | 置き場所 | 実行の速さ |
|---|---|---|---|
| 単体 | 中心の処理 | 同じファイルの `mod tests` | 数ミリ秒 |
| 結合 | 入力アダプタ | `tests/` | 数十ミリ秒 |
| 端から端まで | 実行ファイルとのやり取り | `tests/mcp_stdio.rs` | 1件あたり100 ms 以内 |

## 適用範囲外

| 何を | どの層が決めるか |
|---|---|
| 確かめる単位の境界 | アーキテクチャ |
| テストの置き場所 | 言語 × アーキテクチャ |

## 委譲する判断

| 委譲する判断 | 委譲先 | 委譲する理由 |
|---|---|---|
| 能力ごとの引数の最小形 | 実装 | 能力の設計で決まる |
