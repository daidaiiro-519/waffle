# テスト観点 ── 何を確かめるかの一覧

## 概要

**観点は、規約ではなく技法である。**
言語にも用途にも依らないので、ここに一覧を置き、**採るかどうかは用途の規約が宣言する**。

## 観点

| 観点 | 何を確かめるか | 効く場面 |
|---|---|---|
| 正常系 | 期待された入力で、期待された結果になる | すべて |
| 境界値 | 上限・下限・その前後で振る舞いが変わらない | 上限が契約に在るとき |
| 異常系 | 壊れた入力・欠けた入力を、失敗として扱う | 外部から入力を受けるとき |
| 冪等性 | 同じ入力を2度与えても、結果が同じになる | 再試行される可能性があるとき |
| 順序非依存 | 実行の順を変えても結果が変わらない | 並列に走るとき |
| 並行性 | 同時に走らせても、状態が壊れない | 常駐して複数を受けるとき |
| 障害注入 | 外部が失敗したとき、こちらが壊れない | 外部へ依存するとき |
| 資源の解放 | 失敗した経路でも、資源が返る | ファイル・接続を持つとき |
| 後方互換 | 前の版の入力を、いまの版が受け付ける | 契約を公開しているとき |
| 性質テスト | 入力を機械的に広げても、性質が保たれる | 入力の形が広いとき |

## 採り方

| 手順 | 内容 |
|---|---|
| 1 | 用途の契約を読み、そこに現れる制限（上限・順序・再試行）を書き出す |
| 2 | 制限に対応する観点だけを採る |
| 3 | 採らない観点は、**採らない理由を書く** |

**全部を採らない。**
採る理由が書けない観点は、確かめる対象が無い。

## 観点と単位の対応

| 観点 | 確かめる単位 |
|---|---|
| 正常系・境界値・異常系 | 単体 |
| 冪等性・後方互換 | 端から端まで |
| 順序非依存・資源の解放 | 単体・結合 |
| 並行性・障害注入 | 結合 |
| 性質テスト | 単体 |

## カバレッジ

**下限を規約にしない。**
数値は「どれだけ実行されたか」であって、「何を確かめたか」ではない。

| 使い方 | 内容 |
|---|---|
| 使う | 未到達の行を一覧し、確かめ漏れを探す |
| 使わない | 下限を通過の条件にする |
