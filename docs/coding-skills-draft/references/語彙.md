# 語彙 ── この Skill が使う語

## 概要

**同じ意味に2つの語を当てず、違う意味に同じ語を当てない。**
迷ったら、この表に戻る。

## 語

| 語 | 何を指すか | 例 |
|---|---|---|
| **規約** | 1本の文書。ファイル1つ。**
種別ごとに構造が違う** | `constraints/lang.rust/failure.md` |
| **規則** | 守るべき言明1件。規則の規約と保証の規約だけが持つ | 「回復できる失敗は `Result` で返す」 |
| **宣言** | 構造や道具を並べた表と図。規則ではない | 層の一覧、依存の可否、道具と版 |
| **軸** | 変えられるもの。言語・アーキテクチャ・用途・実行環境 | 言語＝`rust` |
| **種別** | 規約の型。構造／規則／道具／保証の4つ | `failure.md` は規則 |
| **層** | その制約が依存する軸の集合。宣言から導出される | `lang.rust+arch.hexagonal` |
| **下位へ委ねる判断** | 上位が決めず、下位が決めてよいと宣言した1点 | 失敗の列挙の粒度 |
| **正本** | 承認を経た規約が置かれる場所 | `constraints/` の下 |
| **集める** | 軸の値が一致した規約を、正本から取り出すこと | `scripts/collect.py` |

## 使わない語

| 使わない語 | 代わりに | なぜ |
|---|---|---|
| ルール | 規則／規約 | 1件を指すのか文書を指すのかが決まらない |
| ガイドライン | 規則 | 守らなくてよいものに見える。守らなくてよいなら、規則として置かない |
| ベストプラクティス | 規則 ＋ 出典 | 出典を持たない言明は、この Skill では置けない |

## 数え方

| 数えるもの | 単位 |
|---|---|
| 規則 | 件 |
| 規約 | 本 |
| 層 | ── 数えない。軸の組み合わせが現れた数だけ在る |
