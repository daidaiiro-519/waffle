# 語彙 ── この Skill が使う語

## 概要

**同じ意味に2つの語を当てず、違う意味に同じ語を当てない。**
迷ったら、この表に戻る。

## 語

| 語 | 何を指すか | 例 |
|---|---|---|
| **制約** | 1件の言明。検査できる最小の単位 | 「回復できる失敗は `Result` で返し、`panic!` で流さない」 |
| **規約** | 同じ層の制約をまとめた1本の文書。ファイル1つ | `constraints/lang.rust/failure.md` |
| **軸** | 変えられるもの。言語・アーキテクチャ・用途・実行環境 | 言語＝`rust` |
| **層** | その制約が依存する軸の集合。宣言から導出される | `lang.rust+arch.hexagonal` |
| **穴** | 抽象側が「ここは各自が決める」と宣言した1点 | 失敗の列挙の粒度 |
| **正本** | 承認を経た規約が置かれる場所 | `constraints/` の下 |
| **集める** | 軸の値が一致した制約を、正本から取り出すこと | `scripts/collect.py` |

## 使わない語

| 使わない語 | 代わりに | なぜ |
|---|---|---|
| ルール | 制約／規約 | 1件を指すのか文書を指すのかが決まらない |
| ガイドライン | 制約 | 守らなくてよいものに見える。守らなくてよいなら、制約として置かない |
| ベストプラクティス | 制約 ＋ 出典 | 出典を持たない言明は、この Skill では置けない |

## 数え方

| 数えるもの | 単位 |
|---|---|
| 制約 | 件 |
| 規約 | 本 |
| 層 | ── 数えない。軸の組み合わせが現れた数だけ在る |
