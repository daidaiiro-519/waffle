# scripts ── 機械が回すもの

## 概要

**集める・検証する・索引を出すの3つを、機械が行う。**
同じ問いに同じ範囲が返らないと、そのあとの推論の入力が毎回変わるためである。

## 置くもの

| 命令 | 何をするか | 返すもの |
|---|---|---|
| `collect.py --lang <言語> --purpose <用途>` | 軸の値が一致する規約を集める | 規約と、その中の規則。0件の層も、0件として出す |
| `check.py` | 規約の形を検証する | 欄の欠け、出典の空、フォルダ名と宣言した軸の食い違い |
| `index.py` | 人が読む索引を作り直す | 層ごとの一覧（生成物。手で書き換えない） |

## 検証すること

| 検査 | 落ちる条件 |
|---|---|
| 欄の欠け | 言明・依存する軸・出どころ・検め方のどれかが空 |
| 出典 | 原文で照合する文字列が空、または原文に無い |
| 置き場所 | フォルダ名と、宣言した軸が食い違う |
| 重なり | 同じ対象について2つの規則があり、どちらも「下位へ委ねる」と宣言していない |

## 生成物

**索引は生成物である。**
`INDEX.md` を手で書き換えない。
書き換えても、次の生成で消える。

## 検証すること（実装したもの）

| 検査 | 落ちる条件 |
|---|---|
| 前置きの欠け | `id` ・ `layer` ・ `category` ・ `declares` ・ `updated` のどれかが無い |
| 軸の宣言 | 依存する軸が宣言されていない |
| 節の欠け | 「概要」「適用範囲外」「委譲する判断」「出典」のどれかが無い |
| 置き場所 | 宣言した軸が、ディレクトリにも `provides` にも無い。またはその逆 |
| 埋めていない箇所 | 本文に `《…》` が残っている |
| **出典の照合** | **出典の URL の原文を落としていない。または、照合する文字列がその原文に無い** |
| ID の重なり | 同じ層で、同じ ID が2度使われている |

**出典の照合が、いちばん多く捕まえた** ── 落とした原文と突き合わせた時点で、
記憶で書いていた文字列が17件見つかった。

## 原文の置き場所

```
sources/     落とした原文。source-fidelity の `source.py fetch` で取る
```

**原文を落としていない出典は、検査が落とす。**
URL を書くだけでは、その先に何が書いてあるかを誰も確かめていない。
