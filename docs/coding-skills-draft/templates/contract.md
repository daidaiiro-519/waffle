# 《用途》の契約

## 概要

**《呼び出し元と何をやり取りするかを一文で》**

## 契約の内容

| 項目 | 定め |
|---|---|
| 入力 | 《受け取る形式と経路》 |
| 出力 | 《返す形式と経路》 |
| 成否の伝え方 | 《終了コード／状態コード／応答の欄》 |
| 診断 | 《人が読む記録の出し先》 |
| 上限 | 《大きさ・件数・時間の上限》 |

## やり取りの流れ

```mermaid
《呼び出し元とのやり取り。系列図で書く》
```
