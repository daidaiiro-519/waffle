**《何を定める規約かを一文で》**

## 規則一覧

|---|---|---|---|---|

## 規則の詳細

### 《PREFIX-01》　《規則を一文で》

| 項目 | 内容 |
|---|---|
| 水準 | 《必須／禁止／推奨》 |
| 根拠 | 《なぜこの規則が要るか。一文》 |
| 検証方法 | `《コマンド》` または 《レビューで見る箇所》 |
| 例外 | 《規則が適用されない条件。無ければ「なし」》 |
| 既存コードへの適用 | 《新規のみ／改修時に是正／一括是正》 |

**適合例**

```《言語》
《この規則を満たす最小の例》
```

**違反例**

```《言語》
《この規則だけを破っている最小の例》
```
