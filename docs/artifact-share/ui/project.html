入っているアーティファクトと、寄せられたコメントをまとめてzipで取り出します。公開は維持されます。

公開を止める

止めるとプロジェクトのURLは開けなくなりますが、中のアーティファクトは個別のURLと閲覧トークンで引き続き見られます。データは消えず、あとから再公開できます。渡したプロジェクト閲覧トークンは無効になりません——相手を外したいときは〈配布先〉から無効にしてください。

配布先

配布先ごとに閲覧トークンを1本ずつ発行します。1本が1つの配布先で、人数は問いません。無効にするのも1本ずつで、他の配布先には及びません。一度無効にすると元へは戻せません。

閲覧トークンを発行する

あとでどれを無効にするか選ぶための手がかりです。プロジェクトの表示名とは別のものを付けます。

置いておく場として使うため、プロジェクトは期限なしも選べます（アーティファクト1件ずつの閲覧トークンは、必ず期限を持ちます）。
